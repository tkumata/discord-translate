## 目的と範囲

拡張起動時の保存済み翻訳先に応じ、ChatGPT 補助または既存の `scripts/start-server.sh` を自動起動する。
翻訳先切替では旧サーバを停止し、選択先を起動する。拡張無効化・Chrome 完全終了でも自分のサーバを停止する。
OFF では選択先を維持する。手動サーバや別プロフィールのサーバは停止・引継ぎしない。
依存、権限、自動翻訳、モデル取得、翻訳 HTTP・認証・queue・cache の変更を含めない。
直前のサプライチェーン対策の完了範囲には混ぜない。

## Task 2: ローカル Native host と停止

- Result: 実装・自動検証・実モデル確認済み。
- caller origin から CORS を設定し、絶対パスの `start-server.sh` を起動する。モデルの既定値と検証は既存スクリプトが所有する。
- 子プロセスのポート8080所有と `/health` 応答を120秒以内に確認し、Native ready を通知する。worker は130秒を上限とする。
- EOF・signal・切替・異常終了で起動途中を含む子プロセスグループを停止する。SIGTERM 後1秒で SIGKILL へ進む。
- 起動中の lsof / HTTP も中止可能にする。ready 後の子プロセス終了で Native 接続を閉じる。
